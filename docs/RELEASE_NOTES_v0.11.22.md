# v0.11.22 — 시나리오 예고 타이틀 카드 한글화

각 화 시작 전에 뜨는 **예고 타이틀 카드**가 한글로 나옵니다.

```
第 １ 話                     제 1 화
救出!!Zガンダム       →      구출!! Z건담
```

세 게임 전부, **제목 141개**를 다시 그렸습니다.

| 게임 | 화 수 |
|---|---|
| 제2차 | 26 |
| 제3차 | 51 |
| EX | 64 |

「第」「話」 글자도 「제」「화」로 바꿨습니다.
위쪽 영문 부제(`Scenario: 1 / Z-GUNDAM TO THE RESCUE!`)는 원작 그대로 뒀습니다 —
일본어가 아니라 원래 연출입니다.

## 어떻게 찾았나

이 제목들은 텍스트가 아니라 **그림**입니다. 게임 파일 어디를 뒤져도 글자로는
안 나옵니다. 실행파일 폰트를 통째로 한글로 바꿔도 예고 화면만 일본어로 남았던
이유입니다.

에뮬레이터 세이브스테이트에서 꺼낸 VRAM 을 4bpp 로 펼쳐 보면 제목 그림이
눈에 보입니다. 그 픽셀 줄을 게임 파일들의 압축 해제 결과에서 거꾸로 찾아
출처를 확정했습니다.

| 대상 | 위치 |
|---|---|
| 예고 제목 그림 | `EFFECT.BIN` 멤버 **164~172** |
| 예고 배경(SUPER ROBOT WARS 무늬) | 같은 파일 멤버 150 |

찾는 데 두 번 헛발질했습니다. ①VRAM 렌더 PNG 로 좌표를 되짚을 때 렌더 시작
오프셋이 7,640바이트 어긋나 있었고, ②이 리소스는 **니블이 뒤집힌 4bpp** 라
바이트 그대로 찾으면 안 나옵니다.

## 리소스 형식 (새로 푼 것)

`EFFECT.BIN` 안의 그림은 TIM 이 아니라 게임 자체 포맷입니다.

```
[BE16 개수][16바이트 레코드 × 개수][CLUT 여러 벌][픽셀]
레코드 = [BE32 오프셋][a][b][폭][높이][기준점x][기준점y]
```

기준점이 `(폭,높이)` 면 오른쪽아래 기준(일본어 제목 — 화면 오른쪽에 붙습니다),
`(0,0)` 이면 왼쪽위 기준(영문 부제)입니다.

## 그리는 규칙

원본은 **흰 속 + 어두운 테두리 한 겹**입니다(팔레트 인덱스 1 과 3).
한글은 획이 가늘어 원본처럼 '안쪽을 깎아' 테두리를 만들면 속이 사라지므로,
**글자 바깥에 테두리를 두르는** 쪽으로 뒤집었습니다.

칸 크기는 한 픽셀도 안 바꿉니다. 대신 **높이를 먼저 채우고 모자란 가로만
눌러** 그려서, 원문이 4글자인데 한글이 6글자인 제목도 다른 제목과 같은 크기로
보입니다.

## 크기

스트립을 다시 그리면 오히려 압축이 잘 돼서(원본은 가장자리 계조가 지저분합니다)
**파일이 한 바이트도 안 늘었습니다.**

| 멤버 | 원본 압축 | 재압축 | 여유 |
|---|---|---|---|
| 164 (제2차 1~20화) | 35,854 | 31,673 | 4,181 |
| 166 (제3차 1~20화) | 35,111 | 29,096 | 6,015 |
| 171 (EX) | 36,716 | 26,215 | 10,501 |

`EFFECT.BIN` 은 컴플리트 박스와 단독판 3종이 **바이트까지 같은 파일**이라,
한 번 만든 것을 네 디스크에 제자리 교체로 넣었습니다.

## 검증

- 손댄 멤버 9개: 레코드 표가 레트일과 완전 동일 + 지정 범위 밖 변경 0바이트
- 제목 스트립 141개 전부 실제로 교체됨(안 바뀐 것 0)
- 완성 이미지 4종의 `EFFECT.BIN` 해시 일치, 파일 크기 동일
- 기존 게이트 유지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 (6개 이미지)
