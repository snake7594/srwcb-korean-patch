# v0.11.33 — 부대표 목록 밀림 수정 (v0.11.32 과보정)

**v0.11.31·v0.11.32 를 쓰고 계시면 이 버전으로 바꿔 주세요.**
아군부대표 목록이 아래로 갈수록 왼쪽으로 밀렸습니다. 두 번째 실수입니다.

## 무엇이 틀렸나

v0.11.32 에서 "행 끝 복귀 이동을 같이 고쳐야 한다"는 건 맞게 봤는데,
**부대표는 이미 상쇄돼 있었습니다.**

부대표는 두 군데를 고쳤습니다.

- 창 열기 직전 이동 `FC 02 ff`(+2) → `FC 01 ff`(+1)  … **−1**
- 열 이동 `FC 11 fe`(17) → `FC 12 fe`(18)  … **+1**

이 둘이 서로 지워지므로 복귀 이동은 **건드리면 안 됐습니다.** 그런데
출격 쪽과 똑같이 `FC dc`(−36) → `FC db`(−37)로 한 칸 더 빼서, 한 줄에 −1 씩
쌓였습니다.

| | 행 루프 dx 합 |
|---|---|
| 레트일 출격 / 부대표 | −7 / −8 |
| v0.11.32 출격 / 부대표 | −7 ✓ / **−9** ← 밀림 |
| 지금 | −7 ✓ / −8 ✓ |

출격 화면은 v0.11.32 에서도 맞았습니다. 이번에 바뀐 건 **부대표 복귀 이동
한 바이트**뿐입니다.

## 검사기가 왜 못 잡았나

v0.11.32 에 넣은 `verify_list_rows.py` 가 **창 열기 `F7 00 40` 부터** 셌습니다.
그 앞의 `FC dx ff` 도 행 루프 안인데 빼고 세서, 거기서 생긴 −1 이 그대로
빠져나갔습니다. **루프 전체를 세도록 고쳤습니다.**

고친 검사기로 돌려 보면

```
레트일    [-8, -7]      v0.11.30  [-8, -7]      v0.11.32  [-9, -7]  ← 잡힌다
```

## 검증

- 실행파일 5개 + 단독판 3개 전부 dx 합 `[-8, -7]` = 레트일과 동일
- 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 / 원문 잔재 0
- 세이브 머리글·이름 표기 사전·예고 타이틀 카드 검증 통과

v0.11.32 의 인터미션 메뉴 붙여쓰기(`유닛개조`·`유닛능력`·`파일럿능력`·`다음맵`)는
그대로 들어 있습니다.
