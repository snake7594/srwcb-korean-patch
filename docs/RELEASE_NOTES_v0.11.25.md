# v0.11.25 — 유닛 능력 화면 `실드` 값

제보 8건 중 마지막으로 남아 있던 것을 고쳤습니다.

## 무엇이었나

유닛 능력 화면의 이 줄에서 `실드` 뒤 글자가 깨져 있었습니다.

```
원문 : 特殊能力    シールド有
전   : 특수 능력    실드▓
후   : 특수 능력    실드유
```

그 글자는 고정 문구가 아니라 **`無` / `有` 두 칸짜리 표**에서 실행 중에
골라 오는 값이었습니다. 표는 실행파일마다 한 군데씩 있습니다.

| 게임 | 위치 | 전 |
|---|---|---|
| 제2차 | 0x9298 | `끔/켬` |
| **제3차** | **0x9574** | **원문 `無有` 그대로** |
| EX | 0x971C | `무/유` |
| 트레이닝 모드 | 0x9718 | `무/유` |
| 런처(SLPS) | 0x97AC | `끔/켬` |

**제3차만 빠져 있었습니다.** 번역 안 된 자리는 한글 폰트로 렌더돼 뜻 모를
글자가 됩니다.

표기도 두 갈래로 갈려 있었습니다. 실드는 켜고 끄는 것이 아니라 있고 없고이고
원문도 `無/有` 이니 **다섯 곳 전부 `무/유` 로 통일**했습니다. 각각 두 글자
4바이트라 제자리 교체입니다.

## 검증

- 다섯 실행파일 모두 `무유`, 원문 `無有`·옛 표기 `끔켬` 잔존 0
- 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 / 작전목적 0 /
  원문 잔재 0
- 예고 타이틀 카드 그대로(해시 일치)
