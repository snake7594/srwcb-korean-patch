# v0.11.4 — 전투 중 증원 뒤 멈추던 문제 수정

**v0.11.3 을 쓰고 계시면 이 판으로 바꿔 주세요.** 진행이 막히는 문제입니다.

## 원인 — 이벤트 스크립트에 바이트가 끼어 들어갔습니다

v0.11.1 에서 넣은 '레코드 경계 안정화'는, 경계가 어긋난 자리의 **앞 레코드를 한
바이트 늘려** 배치를 다시 잡습니다. 늘리는 방법은 레코드 끝(종결자 앞)에 반각
공백 하나를 붙이는 것입니다. 대사 레코드라면 줄 끝 공백이라 화면에 표가 안 납니다.

그런데 **앞 레코드가 이벤트 스크립트면 이야기가 다릅니다.** 스크립트는 게임의
VM 이 그대로 실행하는 바이트열이라, 거기에 `0x00` 이 하나 끼면 명령이 어긋나
전투 중 증원 같은 이벤트에서 그대로 멈춥니다. v0.11.3 에서는 제2차 시나리오 4의
레코드 0(텍스트가 전혀 없는 순수 스크립트)에 두 바이트가 들어가 있었습니다.

## 고친 방법

이제 **번역으로 교체하는 레코드만** 늘립니다. 그런 레코드는 끝이 텍스트라 공백
하나를 붙여도 무해합니다. 앞쪽에 그런 레코드가 없으면 **그 시나리오는 손대지 않고
남깁니다** — 작전목적의 조건문 표시가 어긋날 수는 있지만, 게임이 멈추는 것보다
낫습니다(제2차 시나리오 4, EX 시나리오 8·23·52·55).

빌드에도 안전장치를 넣었습니다. 스크립트 레코드에는 어떤 경우에도 바이트를 끼우지
않고, 남긴 시나리오는 빌드 로그에 표시합니다.

## 검증

컴플리트 박스와 단독판 3종 모두 — 미번역 0 / 상자 넘침 0 / 깨짐 0.
세 게임 모든 시나리오에서 **이벤트 스크립트 레코드가 원문과 같은 바이트열**임을
확인했습니다.

v0.11.3 에서 고친 대사 밀림(F7 제거)은 그대로 유지됩니다.

## 적용 방법

정품 디스크에서 뽑은 **Track 1 `.bin`** 에 `xdelta` 패치를 적용합니다.

| 대상 | 패치 파일 |
|------|-----------|
| 컴플리트 박스 | `srwcb-second-third-ex-korean-v0.11.4.xdelta` |
| 제2차 단독판 | `srw2-standalone-korean-v0.11.4.xdelta` |
| 제3차 단독판 | `srw3-standalone-korean-v0.11.4.xdelta` |
| EX 단독판 | `srwex-standalone-korean-v0.11.4.xdelta` |

간편 적용판 `srwcb-cb-korean-v0.11.4-easy-apply.zip` 은 `apply.ps1` 을 실행하면
됩니다(xdelta 포함). **에뮬레이터에서는 함께 들어 있는 `.cue` 를 여세요**
(`.ccd` 로 열면 멈춥니다). 컴플리트 박스는 원본 Track 2 를 같은 폴더에
`Super Robot Taisen Complete Box (Track 2).bin` 이름으로 두세요.

**세이브 데이터는 그대로 쓸 수 있습니다.**
