# v0.11.44 — 이름표 밖까지, 네 게임 용어 전면 통일

v0.11.43 은 **인물·기체·무기 이름표 네 개**만 맞췄습니다. 이번에는 **UI 표 열 종을
네 실행파일 전부**(제2차·제3차·EX·**트레이닝**)에 걸쳐 대조했습니다.

---

## 새로 드러난 것 — 제2차만 말이 잘려 있었습니다

지형·정신기·강화 파츠·특기·특수 능력 표는 여태 검사한 적이 없었습니다. 대조하니
**제2차만 극단적으로 축약**돼 있었습니다.

| 일본어 | 제2차 (전) | 제3차·EX·TR |
|---|---|---|
| 丘 | **언** | 언덕 |
| 海 | **해** | 바다 |
| 空 | **공** | 하늘 |
| 愛 | **애** | 사랑 |
| 床 | **바** | 바닥 |
| ハロ | **하** | 하로 |
| イデバリア | **이데B** | 이데 배리어 |
| 切り払い | **베기** | 베어내기 |

원인은 파이프라인 차이입니다. 제3차·EX·TR 은 **표 전체의 상한**만 지키면 되는데,
제2차만 **레코드마다 자기 일본어 폭**에 묶여 축약 사다리로 떨어졌습니다.
네 게임의 표 상한이 **정확히 같다**는 것을 실측으로 확인하고(지형 10칸·정신기 33칸·
강화 파츠 33칸·특기 9칸·능력 10칸) 제2차도 표 상한을 쓰게 했습니다.

| 표 | 갈린 레코드 |
|---|---|
| 지형명 | 25 → **0** |
| 정신기 | 24 → **0** |
| 강화 파츠 | 27 → **0** |
| 특기 | 9 → **0** |
| 특수 능력 | 2 → **0** |
| 무기명 | 1 → **0** |
| 인물·기체 이름표 4종 | 0 (v0.11.43 에서 완료) |

풀린 상한으로 새로 드러난 25건(`콜로니 잔해`·`광자력 연구소`·`강화인간 L1`·
`HP 회복(대)`·`S2 기관`…)도 함께 맞췄고, `실드방어L1`·`베어내기L1` 을
같은 표의 `뉴타입 L1`·`강화인간 L1` 과 양식을 맞춰 띄웠습니다.

## 뜻이 틀렸던 것도 잡혔습니다

- **정신기 `보급`·`행운`류 설명에서 '최대 HP' 가 빠져 있었습니다.**
  `모든 아군 유닛의 HP를 50% 회복` 은 *현재* HP 의 50% 로도 읽힙니다.
  원문은 `最大HPの50%分` 이라 **`모든 아군의 최대 HP 50%를 회복합니다.`** 로 고쳤습니다.
  (지정 아군 30% 판도 같습니다.)
- `ガケ`(절벽)를 **`벽`** 이라 적어 같은 표의 `壁`(벽)과 충돌했고,
  `クレバス` 를 **`균열`** 이라 적어 `裂`(균열)과 충돌했습니다.
- `新早乙女研究所` 를 **`신오토메연구소`** 라 적었습니다(早乙女 를 乙女 로 읽은 오기).

## 이름표가 틀렸던 것 — `ドレン`

대사는 세 곳 모두 **`드렌`**, 이름표만 `도렌` 이었습니다. 확인해 보니 **대사가 맞습니다** —
공식 설정집 영문 표기가 `Dren` 이고 2019년 한국어 더빙도 `드렌` 입니다.
`도렌` 은 옛 일본식 음차입니다. 폭이 같아(3칸) 이름표를 고쳤습니다.

## BGM·예고편 제목

`겟타로보`(제2차) / `겟타 로보`(EX) 처럼 갈리던 것 **56건 중 40건**을 맞췄습니다.
EX·트레이닝이 표기 정규화표를 거치지 않는 경로로 문자열을 읽고 있었습니다.

남은 16건은 메뉴 문구인데, **정규화표에 넣어도 붙은 채로 나옵니다** — 그 게임의
레코드 슬롯이 공백 한 칸을 더 못 받는 것이라 물리적으로 강제된 차이입니다.

## 어떻게 검사했나

네 실행파일에서 표를 통째로 뽑아 **레트일 일본어를 열쇠로** 대조하고, 표 밖은
한글 문자열 2만여 개를 뽑아 공백·한 글자 차이로 짝지었습니다. 대사는 일본어 원장과
번역을 이어 붙여 고유명사가 든 줄을 훑었습니다. 뽑힌 후보는 **판정 → 반대심문**
두 단계를 거쳤고, 반대심문에서 `ドレン` 판정이 뒤집혔습니다(틀린 쪽은 대사가 아니라 표).
