# v0.11.6 — 대사 밀림·잘림의 진짜 원인 수정 + 제3차 맵 명령 메뉴 복원

제보해 주신 **대사가 꼬이고 잘리는** 문제의 원인을 다시 파고들어 근본을 고쳤습니다.
제3차 맵 명령 메뉴(`부대/반격/목적/정신`)도 제2차와 같은 전체 이름으로 되돌렸습니다.

## 1. 대사 밀림·잘림 — 상자 크기를 잘못 알고 있었습니다

지금까지 대사 상자를 **폭 32칸·3줄**이라는 하나의 값으로 놓고 줄을 나눴습니다.
그런데 이 게임의 대사창은 장면마다 크기가 다릅니다. 어떤 장면은 폭이 20칸대이고,
어떤 장면은 두 줄짜리입니다. 넓은 값을 들이대니 좁은 창에서 글자가 상자 밖으로
나가고, 그러면 **게임 쪽 자동 줄바꿈이 대신 끼어들면서** 두 바이트로 그려지는
한글의 앞바이트를 잃습니다. 화면이 낱말 중간부터 시작하거나 첫 글자가 깨져 보이던
그 증상입니다.

이번 판부터 상자 크기를 **원문이 그 장면에서 실제로 보여 준 만큼**으로 잡습니다.

* **폭** — 같은 장면에서 원문이 실제로 줄을 바꾼 가장 넓은 지점
* **높이** — 같은 장면에서 원문이 쓴 가장 많은 줄수

원문이 한 줄로 끝난 대사는 상자 크기를 알려 주지 않으므로, 같은 장면의 다른 대사가
증명한 크기를 씁니다. 한국어가 그 안에 안 들어가면 ① 띄어쓰기를 지우고 ② 그래도
넘치면 낱말 가운데서 줄을 바꿉니다. **번역을 줄여 쓰거나 잘라내지 않습니다.**

같은 규칙을 빠져 있던 곳에도 넣었습니다.

* 줄바꿈 판정 세 군데가 상자 폭 대신 옛 상수(18칸)를 보고 있어, 상자가 18칸보다
  좁으면 검사가 아예 걸리지 않았습니다.
* 보충 번역 주입기(`sce_gap_supplement`)만 옛 바닥값(폭 32·3줄)을 그대로 쓰고
  있었습니다. 제3차에서 마지막까지 남던 여섯 건이 여기서 나왔습니다.

**결과 (실제 대사 전수)**

| | 상자 폭 초과 | 상자 줄수 초과 |
|---|---|---|
| 제2차 4,240 | 0 | 0 |
| 제3차 4,631 | 0 | 0 |
| EX 4,749 | 0 | 0 |

컴플리트 박스와 단독판 3종 모두 같은 결과입니다.

## 2. 제3차 맵 명령 메뉴 — 전체 이름으로 복원 (제보 #5)

`부대 / 반격 / 목적 / 정신` 으로 두 글자씩 잘려 있던 것을
`부대표 / 반격명령 / 작전목적 / 정신검색` 으로 되돌렸습니다(제2차와 같은 표기).

원래 레코드는 107바이트인데 전체 이름은 14바이트가 더 필요하고 레코드 안 여유는
9바이트뿐이라, 아무도 쓰지 않는 폰트 꼬리 자리로 레코드를 옮기고 메뉴 포인터를 다시
겨눴습니다. 옮긴 자리의 글리프 번호를 세 게임의 모든 대사·전투·메뉴 레코드에서
찾아 **한 번도 쓰이지 않음**을 확인했습니다.

## 3. 검증

* 미번역 0 / 상자 넘침 0 / 깨진 레코드 0 — 컴플리트 박스, 단독판 3종
* 이벤트 스크립트 레코드는 원문과 같은 바이트열(포인터 재조준 제외) — 전투 중 증원
  뒤 멈추던 v0.11.3 문제가 재발하지 않도록 계속 확인합니다
* 모든 패치는 역적용으로 결과 이미지가 그대로 나오는지 확인했습니다

## 아직 남은 것

**타이틀 데모(예고편) 대사**가 세 게임 모두 일본어로 남아 있습니다. 이 대사는
실행파일 안에 고정 길이로 박혀 있고, 참조가 순차 스트림이라 다른 자리로 옮길 수
없습니다. 제자리 예산으로는 한국어를 절반 가까이 줄여야 들어가는데, 그건 번역을
잘라내는 것이라 손대지 않았습니다. 자리를 넓힐 방법을 계속 찾겠습니다.

## 적용 방법

정품 디스크에서 뽑은 **Track 1 `.bin`** 에 `xdelta` 패치를 적용합니다.

| 대상 | 패치 파일 |
|------|-----------|
| 컴플리트 박스 | `srwcb-second-third-ex-korean-v0.11.6.xdelta` |
| 제2차 단독판 | `srw2-standalone-korean-v0.11.6.xdelta` |
| 제3차 단독판 | `srw3-standalone-korean-v0.11.6.xdelta` |
| EX 단독판 | `srwex-standalone-korean-v0.11.6.xdelta` |

간편 적용판 `srwcb-cb-korean-v0.11.6-easy-apply.zip` 은 `apply.ps1` 을 실행하면
됩니다(xdelta 포함). **에뮬레이터에서는 함께 들어 있는 `.cue` 를 여세요**
(`.ccd` 로 열면 멈춥니다). 컴플리트 박스는 원본 Track 2 를 같은 폴더에
`Super Robot Taisen Complete Box (Track 2).bin` 이름으로 두세요.

**세이브 데이터는 그대로 쓸 수 있습니다.**
