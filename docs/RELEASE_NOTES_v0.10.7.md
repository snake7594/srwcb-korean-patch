# v0.10.7 — 제2차 진행 불가 버그 수정 + 전투 대사 밀림 수정 + 메뉴 정렬

제2차 슈퍼로봇대전에서 **특정 화 시작 시 진행이 멈추던 문제**와 **전투 대사가
잘리거나 밀리던 문제**를 고쳤습니다. 함께, 제3차·EX·트레이닝 모드의 **메뉴 칸
정렬**도 원본에 맞게 다시 맞췄습니다.

## ① 제2차 브리핑 진행 불가 (프리즈) — 수정

8화처럼 맵에 들어가기 전 대화(브리핑)에서 게임이 멈추는 문제가 있었습니다.

각 시나리오의 브리핑 대화는 시나리오 데이터 안의 **이벤트 스크립트**가 대사를
하나씩 가리키며 진행합니다. 그런데 한글화로 대사 데이터가 커지면서 대사들의 위치가
이동했는데, 이벤트 스크립트 안의 **대사 포인터는 옛 위치를 그대로** 가리키고
있었습니다(재빌드 도구가 이 포인터를 갱신하지 않음). 그래서 브리핑이 대사 중간의
엉뚱한 데이터를 읽어 "다음"으로 넘어가지 못하고 멈췄습니다. **21개 시나리오**가
같은 문제를 안고 있었습니다.

- 이벤트 스크립트의 대사 포인터 **248개를 올바른 대사로 재조준**했습니다.
- 8화 브리핑이 `라라아「저는…킬리만자로 기지에 남겠습니다」` → `아무로「라라아!?
  왜!?」`… 순서대로 정확히 진행됨을 확인했습니다.

## ② 제2차 전투 대사 밀림/잘림 — 수정

전투 중·후 대사가 한 줄에 들어갈 내용인데도 이상하게 줄이 나뉘고 밀려 보였습니다.

전투 대사는 시나리오 대사와 **다른 방식**으로, 넉넉한 한 줄(폭 40)에 표시됩니다.
그런데 한글 코덱이 시나리오용 좁은 줄바꿈(폭 18)을 전투 대사에도 적용해, 원래
한 줄짜리 대사를 억지로 두세 줄로 쪼갰습니다(불필요한 줄바꿈 5,563개).

- 잉여 줄바꿈을 걷어내고 전투 박스 폭(40)에 맞게 다시 정렬했습니다.
- 전투 대사 17,364개 중 **17,313개가 원래대로 한 줄**로 복원되고, 정말 긴 51개만
  폭 40에서 자연스럽게 줄바꿈됩니다. 격추/사망 대사(2_DEAD)도 동일하게 고쳤습니다.

## ③ 제3차·EX·트레이닝 메뉴 정렬 (v0.10.6 통합)

시스템 설정·인터미션·전투 메뉴의 칸 정렬이 게임마다 어긋나던 것을, **제2차의
검증된 번역·정렬을 기준으로 통일**했습니다. 무리한 축약 대신 띄어쓰기를 정리하는
방향으로, 좌우 2칸 시스템 설정창을 포함해 칸 넘침 없이 맞췄습니다(게임당 104개
메뉴 레코드 교정, 셀 단위 폭 어긋남 0).

## 검증

- 모든 수정은 **레코드 시작·포인터·표·파일 크기를 그대로 둔 제자리 수정**입니다.
- 프리즈: 이벤트 참조 재조준 후 스테일 참조 0건, 8화 브리핑 대화 순서 정상.
- 밀림: 전투·사망 대사 전부 폭 40 이내 확인, 크기/포인터 불변.
- ISO 42개 파일 중 실제 변경은 `2_SCE.BIN`·`BMESS2.BIN`·`2_DEAD.BIN`과
  메뉴 정렬분(`EX.WAR`·`THIRD.WAR`·`TR.WAR`)뿐.
