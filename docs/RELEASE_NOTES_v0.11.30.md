# v0.11.30 — 전투 대사에 일본어가 남아 있던 자리 (비참조 레코드)

제보하신 **제3차 전투 대사 일본어**를 전수 조사해서 고쳤습니다.

## 왜 검사에 안 걸렸나

전투 대사 아카이브(`BMESS2/3/4`)는 블록마다 **잎 노드(0x10/0x11)** 가 가리키는
레코드를 모읍니다. 원장도, 검사기도 **그 잎이 가리키는 것만** 봤습니다.

    제3차 전투 대사 16,238건 — 미번역 0

그런데 잎이 안 가리키는데도 **게임이 읽어 화면에 내는** 인용 레코드가 아카이브
마다 수십 개 더 있습니다. 이쪽이 통째로 번역에서 빠져 있었고, 검사기도 아예 안
보고 있었습니다. 하필 그 대부분이 **제타 건담 편**(카미유·포우·로자미·하만·
시로코)이라 제3차 12~16화에서 유난히 많이 보였습니다.

| | 참조 레코드 | 비참조 레코드 |
|---|---|---|
| 제2차 | 17,364 (일본어 0) | 1,145 중 **일본어 54** |
| 제3차 | 16,238 (일본어 0) | 1,075 중 **일본어 54** |
| EX | 18,829 (일본어 0) | 1,203 중 **일본어 52** |

## 어떻게 고쳤나

재배치기는 비참조 레코드를 **바이트 그대로** 남깁니다 — 누가 가리키는지 모르니
옮길 수 없습니다. 그래서 **길이를 한 바이트도 안 늘리고 제자리에** 넣었습니다.
남는 자리는 닫는 낫표 뒤를 반각 빈칸으로 채웁니다(화면에는 안 보입니다).

한국어는 한 글자가 2바이트, 일본어 가나는 1바이트라 자리가 아주 빡빡합니다.
예산에 맞을 때까지 문장을 줄였습니다.

```
「ハマ-ン=カ-ン![F6] お前は,戦いの意志を生む源だ![F6] 生かしてはおけない!」   47B
「하만 칸![F6] 넌 싸움의 근원![F6] 살릴 수 없다!」                           44B
```

새 자산: **`translation/bmess_unreferenced_ko.json`** (58종) ·
**`audit/fix_bmess_unreferenced.py`**(주입기 겸 자리 검사기).
세 아카이브에 **160곳** 들어갑니다.

## 재발 방지

`audit/verify_image.py` 에 **비참조 전투 대사 검사**를 넣었습니다. 참조
레코드만 세던 기존 검사와 달리, 잎이 안 가리키는 인용 레코드까지 훑어 일본어가
남아 있으면 빌드를 세웁니다.
