## 고친 것

### ① 트레이닝 모드 UI 33곳 (가장 눈에 띄던 문제)

트레이닝 모드에서 **항상 화면에 뜨는 UI가 일본어로 남아** 있었습니다. 트레이닝
모드는 EX와 같은 엔진이라 EX에는 이미 번역·폭검증된 같은 문자열이 있었는데,
트레이닝 모드로 옮겨오는 과정에서 이 묶음이 통째로 빠져 있었습니다.

`아군 부대표` · `적군 부대표` · `발진표` · `부활표` · `유닛` · `LV순` · `기력순` ·
`반격 개시` · `반격 불능` · `출격 전함 선택` · `출격 유닛 선택` ·
`여기선 출격 불가!` · `좋습니까?` · `레벨 업` · `정신기「」습득!` ·
`특수 기능「」` · `강화 파츠「」` 등 33곳을 EX의 검증된 번역으로 채웠습니다.

`트레이닝 모드를 종료할까요?` 는 트레이닝 모드에만 있는 문장이라 새로 번역했습니다.

### ② 옵션 모드의 작품명·음악 제목 (EX·트레이닝 모드)

캐릭터 사전 / 로봇 대도감 / 사운드 선택 / 데모 선택에서 작품명과 곡 제목이
일본어로 나오던 것을 한글로 바꿨습니다. 번역문이 원문보다 길어 자리에 안 들어가던
것이라, 레코드를 옮기고 포인터를 다시 겨눠 해결했습니다.

`초전자 로보 컴배틀러 V` · `무적강인 다이탄 3` · `UFO 로보 그렌다이저` ·
`마지막 사자 -카오루-` · `열풍!질풍!사이버스터` · `「정조 미오의 존가라부시」` ·
`「힘과 기술」` · `「교향곡 제9번 라단조 제4악장에서」` 등.

`전환 고정`(사운드 설정)과 EX 예고편 대사 1줄도 함께 번역했습니다.

## 확인된 정상 항목

- **제2차·제3차의 대사·UI는 미번역 0건**이었습니다. 검사에서 일본어로 보이던
  것들은 전부 **번역 후 남은 죽은 사본**(게임이 더 이상 읽지 않는 자리)임을
  포인터를 따라가 확인했습니다.
- 이름 입력 화면의 **가나 입력판(あいうえお / アイウエオ)은 의도적으로 일본어를
  유지**합니다. 일본어 이름을 입력할 수 있어야 하기 때문입니다.
- 선택지 창 한 곳이 폭 18을 넘지만, **원문(23)보다 좁아(22)** 정상입니다.
  선택지 창은 대사창보다 넓습니다.

## 검증

모든 수정은 **파일 크기·표·기존 포인터를 그대로 둔** 방식입니다. 새로 넣은 한글은
폰트에서 쓰지 않는 글리프 자리에 두고 포인터만 다시 겨눴으며, **살아 있는 글자가
그 자리를 쓰지 않는지** 역방향으로 확인했습니다(충돌 0건).

- ISO 42개 파일 중 실제 변경은 `EX.WAR` · `TR.WAR` 둘뿐 (섹터 8개)
- 모든 패치는 xdelta 역적용으로 결과 이미지가 재현되는지 확인
