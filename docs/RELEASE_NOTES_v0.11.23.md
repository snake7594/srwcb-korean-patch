# v0.11.23 — 대사 잘림 수정 + 원문이 그대로 남아 있던 자리들

제보 8건을 받아 전부 원인까지 파고들어 고쳤습니다(1건은 추적 중).

## 1. 대사가 잘리고 화자가 사라지던 것 — **한 줄이 한 칸 넘쳤습니다**

대사창은 32칸이지만 **32칸을 꽉 채운 줄은 게임에서 반 칸이 넘칩니다.**
넘치면 렌더러가 자동으로 줄을 접는데, 그때 두 바이트짜리 글자의 앞 바이트를
잃어버려 **화자 이름이 통째로 사라지고 문장 중간부터** 나옵니다.

```
전 : (첫 줄이 32칸)          →  화면: …!잭, 준비됐어?」
후 : 미치루「왔어 메카자우루스야!잭,
     준비됐어?」
```

한 줄 한도를 **31칸**으로 낮췄습니다. 32칸이던 줄이 세 게임 합쳐
**2,178개** 있었습니다 — 그만큼 곳곳에서 잘리고 있었습니다.

같은 값이 파일 네 곳에 흩어져 있었는데(코덱·빌더·갭 보충·EX 적용) 이제 전부
한 상수를 씁니다. 감사기 기준도 31로 맞췄습니다.

## 2. 번역이 안 된 자리가 **뜻 모를 한글**로 나오던 것

폰트를 한글로 갈아 끼웠기 때문에, 번역이 안 된 레코드는 화면에서 일본어가
아니라 엉뚱한 한글로 나옵니다.

```
원문 : 早乙女研究所 / 光子力研究所      (10화 뒤 진행 경로 선택)
전   : 건걷걸근귿글 / 궈궉겁근귿글
후   : 사오토메 연구소 / 광자력 연구소
```

감사기는 "한글이 보이니 통과"시켜서 이 부류를 오래 놓쳤습니다. **레트일과
바이트를 대조**하는 방식으로 다시 훑어 아래를 찾아 고쳤습니다.

- 제3차 분기 선택지
- EX 승리조건 **64곳** (`적 전멸`, `적 섬멸`, `페일로드(듀락실) 격파`,
  `이동 요새 격파`, `볼쿠르스격파`)
- 제3차 세이브 확인창, 보너스 경험치, 남은 정신 P, 아군 전멸

같은 검사를 **감사 게이트로 넣었습니다**. 다시는 조용히 지나가지 않습니다.

## 3. 종료 메시지에 일본어가 새어 나오던 것

반죠의 메시지는 조각이 **3개**인데 2개만 등록돼 있어 세 번째가 원문
그대로였습니다(`カァァァムヒアァァァッ!!」`). 조각을 채우고, 한국어가 짧아
남는 꼬리도 빈칸으로 메워 원문이 다음 쪽에 새어 나오지 않게 했습니다.

**더 나빴던 것**: 주입기가 "일본어 앵커가 안 보이면 이미 한글"로 판단해
건너뛰는데, 제3차 실행파일은 중간 산출물에 예전 주입이 이미 박혀 있어서
**번역을 고쳐도 영원히 반영되지 않는** 구조였습니다. 이제 앵커와 경계를
레트일에서 찾아 항상 다시 넣습니다.

같은 종류로, 제3차 UI 주입기가 저장소가 아니라 작업 폴더의 **낡은 번역
사본**을 읽고 있던 것도 고쳤습니다.

## 4. 제3차 UI

| 전 | 후 |
|---|---|
| `미행동 유닛이  기 있 2-다` | `미행동 유닛이 2기 있습니다` |
| `출격유닛선택남은 13▓` | `출격 유닛 남음 13기` |
| `배틀 크래셔` / `배틀마린` (제각각) | `배틀크래셔` / `배틀마린` |

숫자는 커서를 **첫 줄 16칸**으로 옮겨 찍는데, 원문은 그 자리가 빈칸이었지만
한국어가 짧아져(10칸) 글자 위에 겹쳤습니다. 숫자를 10칸으로 옮기고 바로 뒤
이동량을 같은 만큼 되돌려 예/아니오 위치는 그대로 뒀습니다.

유닛 이름은 **원문이 순 가타카나라 구분자가 없는 것 63개**의 띄어쓰기를
없앴습니다(배틀크래셔·Z건담·겟타1·마징가Z·화이트베이스 …).
