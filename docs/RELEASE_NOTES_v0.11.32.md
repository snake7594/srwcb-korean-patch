# v0.11.32 — v0.11.31 목록 밀림 수정 + 인터미션 메뉴 붙여쓰기

**v0.11.31 을 쓰고 계시면 이 버전으로 바꿔 주세요.** 출격 유닛 선택 목록이
아래로 갈수록 왼쪽으로 밀려 화면 밖으로 나갔습니다. 제 실수입니다.

## 무엇을 빠뜨렸나

목록 한 줄은 커서를 옮겨 가며 그리고, **마지막에 다음 줄 시작으로 되돌아옵니다.**

```
[FB ..][F8 01]=유닛명  [FC 13 fe]  [FB ..][F8 01]=파일럿명
[FC 08 fe]  [F8 00]=LV  [FC 01 00]  [F8 83]=레벨  [FC dc 02] ← 복귀(-36)
```

한 줄의 `dx` 합이 레트일 값(출격 −8 / 부대표 −10)이어야 줄마다 같은 x 에서
시작합니다. v0.11.31 은 **가운데 열 이동만** 19→18 로 줄이고 복귀 이동을 그대로
둬서 합이 −9 가 됐고, 한 줄에 한 칸씩 계단처럼 밀렸습니다.

이번에 **복귀 이동에서 같은 만큼 되돌렸습니다.**

| | 열 이동 | 복귀 | dx 합 |
|---|---|---|---|
| 출격 (v0.11.31) | `FC 12`(18) | `FC dc`(−36) | **−9** ← 밀림 |
| 출격 (지금) | `FC 12`(18) | `FC dd`(−35) | −8 = 레트일 |
| 부대표 (v0.11.31) | `FC 12`(18) | `FC dc`(−36) | **−9** ← 밀림 |
| 부대표 (지금) | `FC 12`(18) | `FC db`(−37) | −10 = 레트일 |

v0.11.31 이 노린 열 위치(유닛명 39 / 파일럿 183 / LV 247 / 레벨 286)는 그대로
유지됩니다.

## 재발 방지

**`audit/verify_list_rows.py`** 를 빌드 8단계에 넣었습니다. 목록 행 골격을 찾아
`FC dx` 합을 레트일과 대조하고, 다르면 빌드를 세웁니다. 이 검사를 v0.11.31 에
돌려 보면 다섯 실행파일 전부 실패로 잡힙니다.

## 인터미션 메뉴 붙여쓰기

요청대로 띄어쓰기를 뺐습니다.

| 전 | 후 |
|---|---|
| 유닛 개조 | **유닛개조** |
| 유닛 능력 | **유닛능력** |
| 파일럿 능력 | **파일럿능력** |
| 다음 맵 | **다음맵** |

이미 붙여 쓰던 `무기개조`·`강화파츠`·`환승` 과 표기가 맞습니다. 남는 자리는
반각 빈칸으로 채워지므로 뒤따르는 항목 위치는 그대로입니다.
