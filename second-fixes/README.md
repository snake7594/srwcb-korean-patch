# 제2차 진행불가(프리즈)·전투 대사 밀림 수정 (v0.10.7)

배포본(v0.10.6)의 2_SCE / BMESS2 / 2_DEAD 를 **제자리 후처리**로 고친다.
레코드 시작·포인터·표·파일 크기를 모두 보존하므로 이미지 재배치가 없다.

## fix_sce_event_refs.py — 브리핑 프리즈
각 시나리오의 브리핑 대화를 구동하는 **pool 내부 이벤트 스크립트(주로 records[0])**
의 B1/B3/B4 대사 포인터를 재조준한다. 재빌드 도구(rebuild_second_sce)는 프리풀
스크립트(block_start..pool_start)의 참조만 재배치하고, pool 안 이벤트 스크립트의
참조는 누락한다. 한글화로 대사가 커져 타깃이 이동했는데 변위는 그대로라 전부
mid-record 를 가리켜 브리핑이 정지했다(21개 시나리오, 참조 248개).
- 레트일에서 각 참조가 가리키던 '레코드 서수'를 알아내, 배포본의 같은 서수 레코드
  새 위치로 변위(u16)만 다시 쓴다.
- 텍스트 대사 안의 우연한 B3/B4 바이트(op 위치 불일치)는 스킵.

## fix_battle_linebreaks.py — 전투 대사 밀림
배틀 대사 렌더러는 시나리오와 달리 폭 40 한 줄에 표시하는데(F7 없으면 X≥40 래핑),
코덱이 시나리오용 18유닛 pre-break 를 배틀·사망 대사에도 넣어 원판 1줄을 쪼갰다
(원장엔 배틀 개행이 하나도 없음 → 배포본 F6/F7 은 100% pre-break).
- 참조되는 레코드에서 잉여 F6/F7 을 걷어내고 폭 40 으로 재줄바꿈.
- 17,364개 중 17,313개가 1줄로 복원, 40 넘는 51개만 폭 40에서 개행. 2_DEAD 동일.

## build_v1007_image.py — 이미지 반영
v0.10.6 이미지에 재조준된 2_SCE 를 제자리로 얹어 v0.10.7 을 만든다(BMESS2/2_DEAD
는 별도 제자리 교체). ISO 목록·크기 불변, 게이트 통과.

## ★근본 수정(향후 재빌드용, 미반영)
`rebuild_second_sce` 가 프리풀 스크립트뿐 아니라 **pool 이벤트 스크립트의 B1/B3/B4
필드상대 오퍼랜드도 스캔·재배치**해야 하고, 코덱은 배틀/사망 대사에 **배틀 모드(폭
40, 자동 줄바꿈)**를 써야 한다. 현재 v0.10.7 은 배포본 후처리로 해결했다.
