# v0.11.31 — 출격·부대표 목록 열 위치

이슈 [#7](https://github.com/snake7594/srwcb-korean-patch/issues/7) 에 남아 있던
두 건입니다. 둘 다 **커서 이동 한 칸** 차이였습니다.

## 목록 한 줄이 그려지는 방식

```
[F7]<창 열기>  [FB ff ff][F8 01]=유닛명  [FC 13 fe]  [FB ff ff][F8 01]=파일럿명
               [FC 08 fe]  [F8 00]=LV  [FC 01 00]  [F8 83]=레벨
```

`FC dx dy` 는 **이름 칸 시작 기준** 상대 이동이라, 열 위치가 이 숫자 하나로
정해집니다. 두 화면이 서로 다른 값을 쓰고 있었습니다.

| | 창 열기 직전 | 이름→파일럿 |
|---|---|---|
| 출격 유닛 선택 | `FC 01 ff` (+1) | `FC 13 fe` (+19) |
| 아군부대표 | `FC 02 ff` (**+2**) | `FC 11 fe` (+17) |

## 1. 출격 화면 — `LV` 숫자가 상자를 넘던 것

이름→파일럿 이동이 19칸이라 레벨 숫자가 x=294 에서 시작합니다. 두 자리면
310 까지 가는데 목록 상자 오른쪽 테두리가 **305** 라 뒷자리가 잘렸습니다.

**18칸으로 당겼습니다.** 숫자는 286 에서 시작해 302 에서 끝나 상자 안에
들어옵니다. 파일럿명·`LV`·레벨이 통째로 한 칸 왼쪽으로 갑니다.

## 2. 아군부대표 화면 — 유닛명만 한 칸 들여써지던 것

창을 열기 직전 이동이 출격은 +1, 부대표는 **+2** 였습니다. 이 한 칸 때문에
부대표에서만 유닛명이 들여써져 보였습니다(출격 x=39 / 부대표 x=47, 아이콘은
두 화면 다 x=24 근처).

**+1 로 당기고**, 뒤따르는 이동을 17→18칸으로 되돌려 **파일럿·LV·레벨은 있던
자리 그대로** 뒀습니다. 창 여는 이동만 건드리므로 앞의 상태 아이콘은 움직이지
않습니다.

## 결과

두 화면의 네 열이 이제 같은 자리에 섭니다.

| | 유닛명 | 파일럿명 | LV | 레벨 |
|---|---|---|---|---|
| 전 (출격) | 39 | 191 | 255 | 294 ← 잘림 |
| 전 (부대표) | 47 | 183 | 247 | 286 |
| **후 (둘 다)** | **39** | **183** | **247** | **286** |

컴플리트 박스 실행파일 5개와 단독판 3개 전부에 같은 값으로 들어갑니다.

## 검증

- 다섯 실행파일 + 단독판 세 실행파일에서 옛 값(`FC 13 fe` / `FC 02 ff`) **0곳**
- 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 / 원문 잔재 0
- 세이브 머리글 정렬·이름 표기 사전·예고 타이틀 카드 검증 통과
