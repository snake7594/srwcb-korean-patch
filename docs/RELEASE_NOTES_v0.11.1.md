# v0.11.1 — 대사 밀림·꼬임, 승리/패배조건, 전투 대사 넘침 수정

제보해 주신 [#4](https://github.com/snake7594/srwcb-korean-patch/issues/4)(제2차)
[#5](https://github.com/snake7594/srwcb-korean-patch/issues/5)(제3차)의 스크린샷을
전부 뜯어본 결과, 서로 달라 보이던 증상들이 **한 가지 원인**에서 나왔습니다.

## 원인 — 대사 상자 크기를 잘못 알고 있었습니다

지금까지 모든 대사를 **폭 18 · 페이지당 3줄**로 고정해 짜 넣었습니다. 실제
상자는 그렇지 않았습니다. 원문이 줄을 바꾼 지점을 전부 모아 재 보니

| | 실제(원문 실측) | 그동안 쓰던 값 |
|---|---|---|
| 시나리오 대사 — 줄 폭 | 어느 시나리오든 24~32 에서 꺾임 → **32 는 확실히 들어감** | 18 |
| 시나리오 대사 — 페이지당 줄수 | 장면마다 **1 / 2 / 3** 으로 제각각 | 항상 3 |
| 전투 대사 — 줄 폭 | **29** | 40 으로 재래핑 |

그래서 대사의 **74%가 원문보다 줄이 많아졌고**, 2줄짜리 상자에 3줄을 넣으니
세 번째 줄이 상자를 넘쳐서

* 다음 대사가 한 줄씩 밀리고 (**대사 꼬임 / 다른 화자의 대사가 나옴**)
* 문장 중간부터 그려지면서 첫 글자가 깨졌습니다 (`ㅎ면, 그것은 악`)

전투 대사는 40 으로 다시 감싸는 바람에 오른쪽으로 삐져나갔습니다.

### 고친 방법

레코드마다 **원문이 실제로 쓴 상자 크기를 읽어** 그 안에 맞춥니다. 일본어가
들어갔던 크기라면 한국어도 확실히 들어갑니다. 원장 번역·갭 보충(제3차·EX)·
전투 대사 재래핑까지 전부 같은 기준으로 통일했습니다.

한 줄에 더 많이 들어가게 되어 오히려 넘김 횟수도 줄었습니다.

| | 이전 | v0.11.1 |
|---|---|---|
| 원문보다 페이지 줄수가 늘어난 대사 | 74% | **0** |
| 세실리 대사 예 | 3줄(2줄 상자) | 2줄 — 원문과 동일 |

## 승리조건 / 패배조건이 엉뚱하게 나오던 문제

작전목적 화면은 조건문을 **레코드 순번**으로 집어 옵니다. 그런데 대사를 가리키는
포인터(B1/B3/B4)는 뒤에 2바이트 위치값을 달고 다니는데, 레코드를 훑는 규칙은
그걸 모릅니다. 번역 후 위치를 다시 잡는 과정에서 그 2바이트에 `0xFF`(레코드
끝 표시)가 우연히 생기면 **레코드가 거기서 끝난 것처럼 보여 그 뒤 순번이 통째로
밀립니다.** 그래서 승리조건 자리에 일본어 원문이나 앞 문장의 꼬리(`괴`)가 나왔습니다.

이제 어긋난 자리 앞 레코드를 한 칸 늘려(줄 끝 공백 하나) 배치를 다시 잡고,
**레코드 경계가 원문과 완전히 같아질 때까지** 되풀이합니다
(제2차 4곳 · 제3차 3곳 · EX 16곳). 빌드에 경계 검사 게이트도 넣어서, 앞으로
이 문제가 다시 생기면 빌드가 멈춥니다.

문제였던 조건문 6개(시나리오 3·4·14) 전부 정상 출력을 확인했습니다.

컴플리트 박스와 단독판 3종 모두, 게임이 읽는 경로 그대로 훑어 확인했습니다.

| 항목 | 레코드 | 미번역 | 상자 넘침 | 깨짐 |
|------|-------:|------:|---------:|-----:|
| 제2차 대사 / 전투 / 사망 | 1,012 / 17,364 / 95 | 0 | 0 | 0 |
| 제3차 대사 / 전투 / 사망 | 2,540 / 16,238 / 157 | 0 | 0 | 0 |

'상자 넘침' 검사도 이번에 기준을 바꿨습니다 — 고정값이 아니라 **원문 레코드가
쓰던 크기**와 대조합니다. 단독판 3종도 같은 표로 전부 0 입니다.

## 적용 방법

정품 디스크에서 뽑은 **Track 1 `.bin`** 에 `xdelta` 패치를 적용합니다.

| 대상 | 패치 파일 | 원본 |
|------|-----------|------|
| 컴플리트 박스 | `srwcb-second-third-ex-korean-v0.11.1.xdelta` | `Super Robot Taisen Complete Box (Track 1).bin` |
| 제2차 단독판 | `srw2-standalone-korean-v0.11.1.xdelta` | `Super Robot Taisen 2.img` |
| 제3차 단독판 | `srw3-standalone-korean-v0.11.1.xdelta` | `Dai 3 Ji Super Robot Taisen.bin` |
| EX 단독판 | `srwex-standalone-korean-v0.11.1.xdelta` | `Super Robot Taisen EX (J).img` |

간편 적용판 `srwcb-cb-korean-v0.11.1-easy-apply.zip` 은 `apply.ps1` 을 실행하면
됩니다(xdelta 포함).

**에뮬레이터에서는 함께 들어 있는 `.cue` 를 여세요.** `.ccd` 로 열면 멈춥니다.
컴플리트 박스는 Track 2(오디오)가 필요하니, 원본 디스크의 Track 2 를 같은 폴더에
`Super Robot Taisen Complete Box (Track 2).bin` 이름으로 두세요.
