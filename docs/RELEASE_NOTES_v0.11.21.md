# v0.11.21 — 제2차 타이틀 메뉴·오프닝 프롤로그 한글화

지금까지 일본어로 남아 있던 **그래픽 텍스트 두 곳**을 한글로 다시 그렸습니다.
컴플리트 박스와 제2차 단독판 양쪽에 들어갑니다.

## 타이틀 화면 메뉴

```
スタート  →  시작
ロード    →  로드
コンティニュー  →  이어하기
```

메뉴는 **3항목 × 3상태 = 9장**의 그림입니다(비선택 회색 / 강조 흰색 / 선택 금색+글로우).
세 상태 모두 원본의 색·기울기·글로우를 그대로 살렸습니다.

## 오프닝 프롤로그

위로 흐르는 도입부 **글판 8장 27줄**을 전부 옮겼습니다.

```
초인적인 두뇌와 뛰어난 결단력을 지닌
한 과학자가 있었다.
그는 치밀한 조사 끝에, 외우주에서 지구로
중대한 위기가 다가오고 있음을 알고,
   …
그리고 지금, 전 세계를 뒤흔들
제2차 슈퍼로봇대전이 시작되려 하고 있다‥‥
```

용어는 본편 번역과 맞췄습니다 (발시온 / 비안 졸다크 / 디바인 크루세이더즈 / DC).

## 어떻게 했나

이 그래픽들은 커스텀 LZ77 로 압축돼 있어 파일에서 글자를 그냥 찾을 수 없습니다.
게임 폰트 인코딩으로도, Shift-JIS 로도 어느 파일에서도 안 나옵니다.

에뮬레이터 세이브스테이트에서 **VRAM 1MB 를 통째로 꺼내** 화면에 올라온 스프라이트를
찾고, 그 픽셀 열을 게임 파일들의 압축 해제 결과에서 역검색해 출처를 확정했습니다.

| 대상 | 위치 |
|---|---|
| 타이틀 메뉴 | `C_SMAP.BIN` 멤버 25 (단독판은 `Z_SMAP.BIN` 같은 멤버) |
| 프롤로그 | 같은 파일 멤버 34 의 **두 번째 스트림** |

글자는 원본에서 규칙을 **배워** 그립니다 — 픽셀마다 배경까지의 깊이를 재고 깊이별로
원본이 쓰던 색을 그대로 씁니다. 글자 바깥 글로우까지 재현됩니다.

**크기는 한 바이트도 안 늘었습니다.** 재압축본을 원래 바이트 범위 안에 넣어
표·파일 크기·다른 멤버 위치가 전부 그대로입니다.

| 대상 | 원본 | 재압축 | 여유 |
|---|---|---|---|
| 게임 선택 화면 (CB) | 51,979B | 50,833B | 1,146B |
| 타이틀 메뉴 (CB) | 72,455B | 71,365B | 1,090B |
| 타이틀 메뉴 (단독판) | 75,477B | 74,405B | 1,072B |
| 프롤로그 | 32,424B | 30,625B | 1,799B |

## 검증

- TIM 무결성: 패치 전후 TIM 목록 동일 + 지정 범위 밖 변경 0바이트
- 아카이브 표·다른 멤버 바이트 전부 불변, 파일 크기 동일
- 세 게임 × (컴플리트 박스, 단독판) 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 /
  작전목적 블록 0 / 깨진 레코드 0 / 레코드 경계 불일치 0
