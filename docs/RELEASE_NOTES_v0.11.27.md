# v0.11.27 — 인물·기체 이름 표기 통일 (202곳)

같은 인물·기체가 자리마다 다르게 불리던 것을 하나로 맞췄습니다.

## 제보하신 것

**`콰트로` → `크와트로`** — 제3차 대사만 전부 잘못돼 있었습니다(70곳).
제2차·EX 는 이미 `크와트로` 였습니다.

## 같은 부류로 더 찾은 것

이름표(로스터)를 기준으로 삼아, 원문에 이름이 나오는 **모든 대사**를 대조했습니다.

| 토크완 | 토쿠완 |
| 웬돌로 | 웬드로 |
| 드랏체 | 드라체 |

## 이름표 쪽 오타도 있었습니다

대사가 맞고 표가 틀린 경우입니다.

| 원문 | 전 | 후 |
|---|---|---|
| `トッポ` | 톳타 | **톳포** |
| `流竜馬` | 류마 | **료마** |
| `ルセット` | 루셋 | **루세트** |
| `イリア=パゾム` | 일리아 파좀 | **이리아 파좀** |
| `ルセット=オデビー` | 루셋 오데비 | **루세트 오드비** |

## 통짜 치환의 함정

`톳타 → 톳포` 규칙을 넣었더니 **`戸田突太`(톳포의 본명, `토다 톳타`)** 까지
바꿔 버렸습니다. 애칭과 본명이 다른 인물이 있다는 뜻이라, 그 규칙은 빼고
사전에 주의사항으로 남겼습니다.

## 손대지 않은 것

- **로스터의 줄임말** — 칸이 좁아 줄여 쓴 것(겟타 팀 `リョウ` 짧은 이름 `료마`,
  대사 화자 태그는 `료`)은 원문도 같은 구조라 그대로 뒀습니다.
- **기체명 띄어쓰기** — 로스터는 붙여 쓰고(`Z건담`) 대사는 띄어 씁니다(`Z 건담`).
  칸 폭이 다른 자리라 이형 표기로 보지 않았습니다.

## 재발 방지

`translation/glossary_names_ko.json` 에 표준 표기와 이형 목록을 못박았습니다.

```
python audit/fix_name_spellings.py          # 확인만
python audit/fix_name_spellings.py --write  # 고치기
```

빌드 8단계에 **이름 표기 검증**을 넣어, 사전과 어긋나면 빌드가 실패합니다.

## 검증

- 완성 파일에서 이형 표기 잔존 **0**
- 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 / 원문 잔재 0
- 예고 타이틀 카드 해시 일치
