# v0.11.28 — 세이브 화면 정렬 + '네/아뇨'

## 1·2. 세이브 화면 — `자료01` 들여쓰기 / `슬롯1` 이 칸에 걸침

머리글 라벨이 `セ-ブデ-タ`(6칸) → **`세이브`(전각 3자)** 였던 게 원인입니다.

전각 글리프는 `1+phase` 칸씩 나아갑니다. **홀수 개**면 phase 가 뒤집히는데,
phase 는 `F6`(줄바꿈)에서만 초기화됩니다. 그래서

- 머리글이 뒤집어 놓은 phase 가 **목록 첫 줄까지** 새어 나가 `자료01` 만 반 칸
  (4픽셀) 밀렸습니다. 둘째 줄부터는 앞 줄의 `F6` 가 초기화해 줘서 멀쩡했고요.
- 라벨이 레트일보다 2칸 짧아, 바로 뒤 커서 이동(`FC 09 00`)으로 찍는 `슬롯1`
  이 레트일보다 12픽셀 왼쪽 — 칸 경계선 위에 앉았습니다.

고친 방법:

| | 전 | 후 |
|---|---|---|
| 라벨 | `세이브` (전각 3 = 4칸, phase 뒤집힘) | **`저장`+반각 2** (5칸, phase 중립) |
| 커서 이동 | `FC 09 00` | **`FC 0A 00`** |

라벨 자리는 **6바이트 고정**이라 한국어로 6칸을 만들 수 없습니다(전각2+반각2 =
5칸이 한계). 모자란 한 칸은 뒤따르는 커서 이동에서 되돌렸습니다. 결과적으로
`슬롯1` 은 **레트일과 같은 x**(라벨 5칸 + 이동 10 = 15 = 레트일 6+9)에 앉고,
목록 첫 줄은 나머지 줄과 정확히 맞습니다. 로드 화면(`로드`)도 같이 맞습니다.

## 3. `예/아니오` → `네/아뇨`

`はい`/`いいえ` 를 쓰는 자리를 전부 통일했습니다. `아니오`(전각 3자)가 좁은
선택 상자를 넘던 것도 함께 없어집니다.

- 실행파일 5개 전부: `아니오`·`아니요` **0곳**
- 표기가 `예`/`아니오`/`아니요`/`아뇨` 로 갈려 있던 것을 **`네`/`아뇨`** 하나로

대사 속 `"아니요, ..."` 같은 **말투는 건드리지 않았습니다** — 선택지 라벨만
바꿨습니다.

## 안 고쳐지고 있던 자리 하나

제3차·EX·트레이닝의 `예/아니오` 두 곳은 번역 소스가 아니라 **pickle 바이너리**
(`third-ui/foreign_recs.pkl`)에 들어 있어서, 사전을 고쳐도 바뀌지 않았고
저장소를 grep 해도 안 나왔습니다. 읽고 고칠 수 있는
**`third-ui/foreign_recs.json`**(바이트 + 사람이 읽는 디코드)으로 바꾸고 pickle
은 지웠습니다.

## 재발 방지

**`audit/verify_save_header.py`** 를 빌드 8단계에 넣었습니다. 실행파일 4개에서

- 라벨 advance + 뒤따르는 커서 이동이 **레트일과 같은지**
- 라벨이 **phase 중립**인지 (아니면 목록 첫 줄이 밀린다)

를 확인하고, 어긋나면 빌드를 실패시킵니다.

## 저장소 쪽 수정

`setup_workspace.py` 가 **`EFFECT.BIN`** 을 안 뽑고 있었습니다(v0.11.22 에서
예고 타이틀 카드가 들어오면서 필요해진 파일). 새로 클론해서 빌드하면 7단계에서
멈췄습니다.
