# v0.11.7 — 대사 밀림·잘림 실제 수정 (v0.11.6 을 쓰지 마세요)

**v0.11.6 은 대사가 더 심하게 깨집니다. 이 판으로 바꿔 주세요.**

## 무엇이 잘못됐었나

제3차 대사가 계속 꼬이고 잘린다는 제보를 받고 상자 크기를 다시 쟀습니다.
세 게임의 **원문 대사 레코드를 전부** 훑은 결과는 명확했습니다.

* 원문이 줄을 바꾼 지점은 **16~32칸**에 몰려 있고, **32칸을 넘는 줄이 하나도 없습니다**
* 한 쪽은 **3줄**까지입니다
* 긴 대사는 원문도 **F7(쪽 나눔)** 으로 나눠 씁니다 — 제2차만 279곳

즉 대사창은 **폭 32칸 × 쪽당 3줄**로 처음부터 정해져 있었습니다.

그런데 v0.11.6 은 "같은 시나리오에서 원문이 줄을 바꾼 가장 넓은 지점"을 상자로
삼았습니다. 문제는 같은 시나리오 안에 **폭 276칸짜리 특수 레코드**가 섞여 있다는
것이었습니다. 그 하나 때문에 그 장면 전체의 상자가 276칸으로 부풀었고, 대사는 줄이
안 나뉜 채 한 줄로 길게 늘어졌습니다. 그러면 게임 쪽 자동 줄바꿈이 대신 끼어들면서
두 바이트로 그려지는 한글의 앞바이트를 잃습니다 — **낱말 중간부터 시작하고 첫 글자가
깨지는** 그 증상입니다.

더 나빴던 건 **검증기도 같은 방식으로 상자를 구했다는 점**입니다. 부풀린 상자로
재니 넘치는 게 없다고 나왔고, 그래서 "폭 초과 0"이라고 보고하면서 실제로는 깨진
판을 내보냈습니다.

정확한 기준(줄 폭 32, 쪽당 3줄)으로 다시 재니 v0.11.6 에는 이런 레코드가
**1,553개**(제2차 340 · 제3차 644 · EX 569) 있었습니다.

## 고친 것

* **상자를 폭 32 × 쪽당 3줄로 고정**했습니다. 시나리오 안에서 상자를 유추하지
  않습니다. 원문이 그보다 크게 쓴 드문 레코드만 그 레코드가 쓴 만큼을 씁니다.
* 긴 대사는 **원문이 그러듯 F7 로 쪽을 나눕니다**(v0.11.3 에서 F7 을 없앤 판단이
  틀렸습니다 — 원문도 씁니다).
* **줄 끝 공백을 버립니다.** 화면에는 안 보이면서 폭만 한 칸 먹어 상자를 넘겼습니다.
* **레코드 경계 안정화가 상자를 넘기지 않게** 했습니다. 이 과정은 레코드를 한 바이트
  늘리는데, 예전엔 줄 끝에 공백을 붙였습니다. 그 줄이 이미 32칸이면 33칸이 되어
  마지막 글자가 잘렸습니다. 이제 쪽에 줄 여유가 있으면 **빈 줄(F6)** 로 늘리고
  (폭이 전혀 안 늘어납니다), 여유가 없는 레코드는 아예 고르지 않습니다.
* **검증기를 고쳤습니다.** 쪽(F7)과 줄(F6)을 갈라 세고, 줄마다 폭을, 쪽마다 줄수를
  봅니다. 이번 판부터는 이 검사를 통과하지 못하면 이미지가 나오지 않습니다.

## 검증

| | 대사 레코드 | 상자 넘침 |
|---|---|---|
| 제2차 | 4,240 | 0 |
| 제3차 | 4,631 | 0 |
| EX | 4,749 | 0 |

컴플리트 박스와 단독판 3종 모두 — 미번역 0 / 상자 넘침 0 / 깨진 레코드 0.
이벤트 스크립트 레코드는 포인터 재조준 외에는 원문과 같은 바이트열입니다(전투 중
증원 뒤 멈추던 v0.11.3 문제 재발 없음).

v0.11.6 에서 넣은 **제3차 맵 명령 메뉴 복원**(`부대표/반격명령/작전목적/정신검색`)은
그대로 들어 있습니다.

## 적용 방법

정품 디스크에서 뽑은 **Track 1 `.bin`** 에 `xdelta` 패치를 적용합니다.

| 대상 | 패치 파일 |
|------|-----------|
| 컴플리트 박스 | `srwcb-second-third-ex-korean-v0.11.7.xdelta` |
| 제2차 단독판 | `srw2-standalone-korean-v0.11.7.xdelta` |
| 제3차 단독판 | `srw3-standalone-korean-v0.11.7.xdelta` |
| EX 단독판 | `srwex-standalone-korean-v0.11.7.xdelta` |

간편 적용판 `srwcb-cb-korean-v0.11.7-easy-apply.zip` 은 `apply.ps1` 을 실행하면
됩니다(xdelta 포함). **에뮬레이터에서는 함께 들어 있는 `.cue` 를 여세요**
(`.ccd` 로 열면 멈춥니다). 컴플리트 박스는 원본 Track 2 를 같은 폴더에
`Super Robot Taisen Complete Box (Track 2).bin` 이름으로 두세요.

**세이브 데이터는 그대로 쓸 수 있습니다.**
