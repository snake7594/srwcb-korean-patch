# v0.11.0 — 누구나 자기 디스크로 이 패치를 만들 수 있습니다

게임 안에서 보이는 것은 v0.10.8 과 거의 같습니다. 이번 판의 핵심은 **저장소만
받으면 이 패치를 처음부터 끝까지 다시 만들 수 있게 된 것**입니다. 지금까지는
제 PC 에만 있던 중간 파일이 여기저기 끼어 있어서, 남이 클론해도 빌드가 중간에
멈췄습니다.

## 게임에서 달라지는 것

| 곳 | 내용 |
|----|------|
| EX 선택지 (마사키 편) | `마사키「아직 입이 살았군‥‥」` → `마사키「입이 살았군‥‥」` — 선택지 창 폭 18 을 3칸 넘겨 글자가 겹칠 수 있었습니다 |

그 외 대사·전투 대사·메뉴는 v0.10.8 과 **문자 단위로 동일**합니다(제2차 대사
1,051 / 제3차 2,650 / EX 3,873 항목 전수 대조, 변경 1건).

## 빌드가 재현 가능해졌습니다

깨끗한 클론 + 정품 디스크만 두고 전 과정을 돌려 확인했습니다.

```bash
python setup_workspace.py --disc "…/Super Robot Taisen Complete Box (Track 1).bin"
python build_all.py
```

가는 길에 막혔던 곳을 전부 고쳤습니다.

### 사라졌던 중간 파일 → 다시 만들게 하거나 자산으로 편입

* **EX 보충 번역 66쌍** — 작업 중 만든 임시 파일에만 있었습니다. 배포된 v0.10.8
  이미지에서 되찾아 [`ex-ui/data/ex_gap_translations.json`](../ex-ui/data/ex_gap_translations.json)
  으로 못박았습니다. 판정 문턱에 걸려 새 나가던 1건(`キ-ン(ニ-‥‥)` → `킨(니‥‥)`)도
  채웠습니다.
* **제3차 시스템 메시지 풀 색인** — 실행파일에서 직접 만듭니다. 이때 타깃이
  레코드 *시작* 인지(앞 바이트가 종결자인지) 걸러야 합니다. 안 그러면 문장
  중간을 가리키는 포인터까지 레코드로 세어 메뉴 정렬이 깨집니다.
* **종료(전원끄기) 메시지 풀**, **제3차 갭 후보 목록**, **EX 단독판 델타 맵** 도
  저장소로 옮기거나 생성 코드로 대체했습니다.

### 저장소에 옛 버전이 올라와 있던 것

* `third-ui/inject_third_ui.py` 가 세 세대 전 버전이었습니다. 최종본으로 교체.
* **EX·트레이닝 모드 주입기가 번역 파일 3종을 엉뚱한 곳에서 찾고 있었습니다.**
  없으면 조용히 건너뛰는 코드라, 다시 빌드하면 일부 UI 가 미번역으로 남고 그
  자리의 일본어 글리프 번호가 한글로 덮인 슬롯을 가리켜 글자가 깨졌습니다.
  (배포된 v0.10.8 이미지 자체는 정상입니다 — 재빌드했을 때만 나던 문제입니다.)

### 이미지 조립을 단일 패스로 다시 썼습니다

예전에는 `v0.8.7 → v0.9.0 → v0.9.3 → v0.9.4 → v0.10.4 → …` 로 이미지를 계속
덮어쓰며 올라갔습니다. 중간 이미지가 없으면 재현이 불가능했고, 버려진 옛 자리에
쓰레기 바이트가 남았습니다. 이제
[`image-build/assemble_image.py`](../image-build/assemble_image.py) 가
**레트일 Track 1 + 바뀐 파일 19개**로 한 번에 만듭니다.

* 크기가 그대로인 실행파일은 제자리에, 커진 10개는 이미지 끝에 이어 붙이고
  디렉터리 레코드(LBA·크기)를 고칩니다.
* 제3차만 파일 위치를 실행파일에 박아 두고 쓰기 때문에 그 23곳을 다시 씁니다.
* **검증**: 배포된 v0.10.8 에서 뽑은 19개 파일로 재조립하면 42개 파일이 전부
  바이트 단위로 같습니다.

### 그동안 이미지를 직접 뜯어 고치던 수정들을 빌드 안으로

v0.10.6~v0.10.8 의 수정은 완성된 이미지에 덧칠하는 방식이었습니다. 그래서 다시
빌드하면 버그가 되살아났습니다. 이제 7단계
([`image-build/build_image.py`](../image-build/build_image.py))가 순서대로 적용합니다.

| | 내용 | 빠지면 |
|---|------|--------|
| 1 | 종료 메시지 한글 주입 | 그 화면만 일본어 |
| 2 | 이벤트 스크립트 포인터 재조준 | **브리핑에서 멈춤** |
| 3 | 전투·사망 대사 사전 줄바꿈 제거 | 전투 후 대사가 밀림 |
| 4 | 메뉴 칸 정렬 교정 (제2차 기준) | 메뉴 글자가 칸을 넘어감 |
| 5 | 잔여 미번역 UI 보충 (트레이닝 ← EX) | 트레이닝 상시 UI 일본어 |
| 6 | 게임 선택 화면 그래픽 한글판 | 부팅 메뉴만 일본어 |

### 단독판(별매 CD)도 클론에서 바로

세 이식 도구가 전부 후처리 **이전** 파일을 쓰고 있었습니다(그래서 단독판은
따로 손봐야 했습니다). 이제 7단계 결과를 옮겨 심고, 끝나면 컴플리트 박스와 같은
기준으로 다시 검사합니다.

```bash
set SRWCB_SRW2_IMG=…   set SRWCB_SRW3_BIN=…   set SRWCB_SRWEX_IMG=…
python setup_standalone.py
python build_all.py --only 9
```

## 적용 방법

정품 디스크에서 뽑은 **Track 1 `.bin`** 에 `xdelta` 패치를 적용합니다.

| 대상 | 패치 파일 | 원본 |
|------|-----------|------|
| 컴플리트 박스 | `srwcb-second-third-ex-korean-v0.11.0.xdelta` | `Super Robot Taisen Complete Box (Track 1).bin` |
| 제2차 단독판 | `srw2-standalone-korean-v0.11.0.xdelta` | `Super Robot Taisen 2.img` |
| 제3차 단독판 | `srw3-standalone-korean-v0.11.0.xdelta` | `Dai 3 Ji Super Robot Taisen.bin` |
| EX 단독판 | `srwex-standalone-korean-v0.11.0.xdelta` | `Super Robot Taisen EX (J).img` |

간편 적용판 `srwcb-cb-korean-v0.11.0-easy-apply.zip` 은 `apply.ps1` 을 실행하면
됩니다(xdelta 포함).

**에뮬레이터에서는 함께 들어 있는 `.cue` 를 여세요.** `.ccd` 로 열면 멈춥니다.
컴플리트 박스는 Track 2(오디오)가 필요하니, 원본 디스크의 Track 2 를 같은 폴더에
`Super Robot Taisen Complete Box (Track 2).bin` 이름으로 두세요.
