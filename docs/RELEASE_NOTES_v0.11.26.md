# v0.11.26 — 예고 타이틀 카드 글자 잘림 수정

v0.11.22 에서 넣은 시나리오 예고 타이틀 카드의 한글이 **위아래가 잘려** 있었습니다.
**141개 전부** 해당했습니다.

## 무엇이 잘못됐나

한글을 **칸(스트립) 전체에 맞춰** 그린 뒤, 획을 살리려고 **테두리 1픽셀을
바깥에 덧그렸습니다.** 그만큼 칸을 넘쳐서 위아래가 깎였습니다.

| 칸 | 원본 글자 높이 | 한글(수정 전) |
|---|---|---|
| 24px (제2차·제3차) | 19~23 | **24 — 꽉 참** |
| 32px (EX) | 22~27 | **32 — 꽉 참** |

좌우까지 닿은 것도 40여 개였습니다. 뭉개진 획이 남은 일본어처럼 보이기도
했습니다.

## 어떻게 고쳤나

칸이 아니라 **원본 글자가 실제로 차지하던 사각형**을 목표로 잡습니다.

- 칸 전체를 먼저 투명으로 지웁니다 — 일본어는 한 픽셀도 안 남습니다
- 한글은 그 사각형 안에, **테두리까지 포함해** 들어가도록 그립니다
- 들어갈 때까지 크기를 줄이는 확인 루프를 넣었습니다

결과: **141개 전부 원본 글자 상자 안**(넘침 0). 화면에서 원본과 같은 자리,
같은 크기로 앉습니다. 압축도 더 좋아져 멤버당 여유가 늘었습니다.

## 빌드 게이트 순서도 고쳤습니다

예고 카드 검증이 8단계에서 **9단계에 만들어지는 단독판**을 검사하는 바람에,
애먼 실패로 **단독판 빌드가 통째로 건너뛰어지고** 있었습니다. 이번에 그
상태로 나갈 뻔한 것을 게이트가 잡았습니다.

- 8단계 → 컴플리트 박스만 검사(`--cb-only`)
- 9단계 뒤 → 단독판까지 포함해 다시 검사

## 검증

- 예고 제목 141개: 원본 글자 상자를 벗어난 것 0
- 이미지 4종의 `EFFECT.BIN` 해시 일치, 파일 크기 동일
- 6개 이미지: 미번역 0 / 대사창 폭·줄 초과 0 / 깨진 레코드 0 / 원문 잔재 0
