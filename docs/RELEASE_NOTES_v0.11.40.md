# v0.11.40 — 대사 한 줄이 스택을 넘어 게임을 죽이던 것

**EX 23화 듀라크실(페일로드) 격파 직후 커서가 사라지고 완전히 멈추던 것**을 고쳤습니다.
원인은 **번역된 대사 한 줄이 7바이트 길었던 것**입니다.

---

## 무엇이 문제였나 — 128바이트 줄버퍼

대사 한 페이지를 조립하는 루틴(EX `0x800C4F04`)은 호출자 `0x800C4D14` 의 스택 프레임
안 **128바이트 버퍼**에 한 바이트씩 써 넣습니다. **길이 검사가 없습니다.**

그리고 같은 프레임 바로 뒤에는 호출자가 저장해 둔 **`s0`·`s1`** 이 있습니다.

```
0x800C4D14   addiu sp,sp,-168        sp = 0x801FFED8
             줄버퍼 = sp+24         = 0x801FFEF0   (128바이트)
             sw s0,152(sp)          = 0x801FFF70   ← 바로 뒤
             sw s1,156(sp)          = 0x801FFF74
```

`s0`·`s1` 은 스크립트 인터프리터가 프롤로그에서 넣어 두는 **디스패치 표 주소**입니다.

```
0x80062B48   addiu s1,v0,0x6A28      s1 = 0x80116A28  (옵코드표)
0x80062B54   addiu s0,v0,0x474       s0 = 0x80010474  (카테고리표)
0x80062B94   addu v0,v0,s0 / lw v0,(v0) / jr v0
```

페일로드 사망 대사가 **135바이트**로 전개되면서 종단자까지 136바이트를 써서
**`s0`·`s1` 정확히 8바이트를 한글 글자 바이트로 덮었습니다.**

```
s0  0x80010474  ->  0xB1ED00AA        s1  0x80116A28  ->  0xFF3FA2F1
```

그 다음 디스패치가 미매핑 주소를 읽어 오픈버스 `0xFFFFFFFF` 를 얻고 **`jr 0xFFFFFFFF`**
로 뜁니다 → **AdEL 주소오류 예외** → BIOS 미해결예외 루프(`SR.IEc=0`, 인터럽트 차단)
→ **RAM 전체가 얼어붙습니다.** 11초 간격으로 뜬 두 상태 저장의 2MB RAM 이 한 바이트도
다르지 않았던 이유가 이것입니다.

## 어떻게 찾았나

1. 멈춘 순간의 상태 저장에서 **커널 TCB 에 저장된 고장 순간의 레지스터**를 꺼냈습니다 —
   `EPC = BadVaddr = 0xFFFFFFFF`, `Cause = AdEL`, `ra = 0x80062B7C`(인터프리터 디스패치 직후),
   그리고 **`s0`·`s1` 이 한글 글자 바이트**.
2. 스택 프레임을 역산해 128바이트 버퍼(`0x801FFEF0`)와 저장된 `s0`(`0x801FFF70`)의 거리를
   구했더니 **정확히 8바이트 초과**였고, 프리즈 RAM 에 그 136바이트가 그대로 얹혀 있었습니다.
3. 그 바이트열을 `EX/E_SCE.BIN` 에서 찾으니 **오프셋 0x4E657** — 페일 사망 대사였습니다.

## 고친 것

| 게임 | 대사 | 전 | 후 |
|---|---|---|---|
| EX | 페일 사망 대사 (sc25·sc27·sc51 세 곳) | **135** | 124 |
| 제3차 | 레코아 | 128 | 126 |
| 제3차 | 메키보스 | 128 | 126 |

제3차 두 줄은 정확히 128이었는데, 종단자까지 129바이트가 되어 **`s0` 의 최하위 바이트를
1바이트 덮습니다.** 같은 부류라 함께 줄였습니다.

## 게이트

`audit/verify_page_bytes.py` 를 빌드 검증에 넣었습니다. 페이지 경계는 조립 루틴과 같게
**3번째 `F6` / `F7` / `FF`** 에서 끊고 `F6` 은 2바이트로 전개해 셉니다.

    기록량 = 페이지 + 1(종단자) ≤ 128   =>   **페이지 ≤ 127**

| | 페이지 최대 | 위반 |
|---|---|---|
| 레트일 EX / 제3차 / 제2차 | 98 / 104 / 100 | **0건** |
| v0.11.39 | 135 | **3건** |
| v0.11.40 | 127 / 126 / 127 | 0건 |

**레트일이 세 게임 모두 0건**이라는 것이 이 한계가 진짜 엔진 규칙이라는 보증입니다.

## 왜 이제야 나왔나

한글은 전각(글자당 2바이트), 일본어 가나는 반각(1바이트)입니다. 레트일은 가장 긴 대사도
98바이트라 30바이트 여유가 있었는데, 우리 번역은 같은 뜻을 담으면서 그 여유를 넘겼습니다.
**이 부류는 대사가 길어질수록 언제든 다시 생길 수 있어서, 문안이 아니라 게이트로 막았습니다.**
