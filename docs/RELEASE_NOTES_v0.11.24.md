# v0.11.24 — 제2차에만 있던 번역을 나머지 셋으로 (515곳)

v0.11.23 바로 뒤에 나온 후속입니다. **제2차만 한글이고 제3차·EX·트레이닝은
원문 그대로**였던 자리를 찾아 옮겼습니다.

## 무슨 일이 있었나

네 실행파일(`SECOND.WAR` / `THIRD.WAR` / `EX.WAR` / `TR.WAR`)은 같은 엔진에서
나와 **공용 문자열이 바이트까지 같은 자리**에 들어 있습니다. 그런데 번역을
제2차부터 해 왔기 때문에, 제2차에서 고친 것이 나머지 셋에는 반영되지 않은
자리가 남아 있었습니다.

폰트를 한글로 갈아 끼운 뒤로 그런 자리는 화면에서 일본어가 아니라 **뜻 모를
한글**로 나옵니다. 그래서 눈에 잘 안 띄었습니다.

가장 큰 덩어리는 **예고편 대사 풀**이었습니다.

```
전 : トウジ「おめっとさん」   →  화면: 뜻 모를 한글
후 : 토우지「축하해」
```

| 대상 | 이식 |
|---|---|
| 제3차 | 83 |
| EX | 210 |
| 트레이닝 모드 | 222 |
| **합계** | **515** |

## 옮기는 규칙

하나라도 어긋나면 건드리지 않습니다.

- 레트일 바이트가 두 파일에서 **완전히 같다**
- 대상 파일은 **아직 레트일 그대로다**(= 번역 안 됨)
- 레트일 내용이 **일본어 문장**이다(바이트코드·기호 제외)
- 길이가 같다 — 제자리 교체라 포인터·레코드 경계가 전부 그대로

EX·트레이닝은 파일 크기와 배치가 달라 오프셋만으로는 안 걸립니다. 그래서
원문 레코드가 제2차에 **딱 한 번만** 나오는 경우에 한해 내용으로 대조했습니다
(중복이면 쓰지 않습니다).
