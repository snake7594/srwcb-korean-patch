# v0.11.43 — 인물·기체·무기 이름을 세 게임에서 하나로 맞췄습니다

같은 인물, 같은 기체, 같은 무기가 **제2차·제3차·EX 에서 다르게 적혀 있던 것**을
전부 맞췄습니다. 다시 갈라지지 않도록 **빌드 게이트**로 막았습니다.

---

## 왜 갈렸나

세 게임은 이름표를 각각 다른 경로로 채웁니다. 제2차는 오버레이에서 그대로 가져오고,
제3차·EX 는 제2차 번역을 일본어로 되짚어 가져온 뒤 **띄어쓰기를 지우는 사전**을
한 번 더 통과합니다. 그래서 **제2차만 띄어 쓰고 나머지 둘은 붙여 쓰는** 상태였습니다.

    제2차  하이퍼 바주카 · 가베라 테트라 · 요츠야 박사
    제3차  하이퍼바주카   · 가베라테트라   · 요츠야박사

거기에 EX 는 인명 구분자로 **`=` 를 그대로** 쓰고 있었습니다(`슈타이너=하디`).

| 표 | 갈린 이름 |
|---|---|
| 무기명 | **46** |
| 짧은 이름 | **12** |
| 전체 이름 | **95** |
| 기체명 | **40** |

## 정한 규칙

1. **무기명은 띄어쓰기를 쓰지 않는다.** (`하이퍼바주카`, `그레이트타이푼`)
2. **인명·직함은 띄어 쓴다.** (`요츠야 박사`, `젊은 여자`, `DC 병사`)
3. **기체명은 일본어에 구분자(`=` `.`)가 있으면 띄고, 없으면 붙인다.**
   (`ガ-ベラ.テトラ` → `가베라 테트라`, `メカ胡蝶鬼` → `메카 호접귀`,
    `ザクⅡ` → `자쿠II`)
4. **붙은 영숫자 모델 표기는 하이픈 없이 붙인다.** (`건담MkII`, `큐베레이MkII`)
5. **`改` 는 뒤에 `개량형` 으로 띄어 붙인다.** (`자쿠 개량형`, `발시온 개량형`)

## 칸 넘침도 함께 잡혔습니다

이름표는 표마다 **레트일 최대 폭**이 곧 상한입니다. 세 게임 모두 기체명 상한이
**15칸**인데, 제3차·EX 는 `사이코건담Mk-II(MA)` 를 **16칸**으로 싣고 있었습니다.
하이픈을 뺀 `사이코건담MkII(MA)` 가 정확히 15칸이라 규칙 4로 함께 해결됐습니다.

**짧은 이름(전투 라벨) 칸은 더 좁습니다** — 제2차 9칸, 제3차·EX 7칸. 그런데 제3차·EX 는
일본어 하나에 한국어 하나만 두므로 짧은 이름과 전체 이름에 **같은 값**이 들어갑니다.
두 표에 다 있는 `もりもり博士`·`早乙女博士`·`人工知能改` 는 그래서 9칸에 들어가는
붙임꼴(`모리모리박사`·`사오토메박사`·`개량인공지능`)로 통일했습니다.
